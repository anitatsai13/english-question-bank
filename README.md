# 英文題庫練習網

國中英語（康軒）題本的線上練習：依 **冊別／課別／主題** 選範圍，可再篩來源（題庫、習作、素養題、會考特色題、歷屆會考）與難易度。

網址：https://anitatsai13.github.io/english-question-bank/

## 題目

| 主題 | 內容 | 作答方式 |
|---|---|---|
| 🔤 單字 | 字彙選擇、文意字彙 | 選擇；文意字彙打字 |
| 📐 文法 | 語法測驗，依文法類別細分 | 選擇 |
| 💬 對話 | 依對話情境選回應 | 選擇 |
| 📖 閱讀 | 短文、對話、書信、圖表、廣告 | 題組（文章在上，依序答小題） |
| 🧩 克漏字 | 克漏字 | 題組 |
| ✏️ 填充 | 依中文／提示填空 | 打字，自動判斷 |

- 寫作題（依提示回答、整句翻譯、看圖回答、句子重組）先不收。
- 打字題不分大小寫、全形半形，’ 和 ' 視為相同；答案有多種寫法的任一種都算對；括號裡的字可省略。

## 共用功能

- **隨機 10／20／30 題**：沒做過 → 答錯還沒訂正 → 答對過（答對越少、越久沒練的先）。最後一次答對就算已訂正。
- **錯題本**：同一題連續答對 3 次移出，中途答錯歸零；可依冊別、主題「只練錯題」，題組只重測錯的小題。
- **學習進度**：各冊各課做過幾題、答對、待訂正。
- **會員登入**：與英文文法學習網、英文單字學習網同一組帳號，錯題與進度存雲端。

## 檔案

- `index.html`：網頁（單一檔案）
- `data/qb.json`：題庫（由建置腳本產生，不要手改）
- `img/`：題目附圖（已壓縮）
- `sw.js`：離線快取；改版時把 `CACHE` 版本號 +1

題庫由 `C:\Users\anita\tools\qbank\build.js`（題本 questions.json → data/qb.json）與 `img.py`（壓縮附圖）產生，`check.js` 檢查題數、答案、題組、填充、圖片。
